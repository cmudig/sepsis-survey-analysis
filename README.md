# Sepsis Survey Study Analysis Code

The repo includes the raw survey responses with demographics and identifiers removed, as well as aggregated outputs and information about the AI predictions. Please contact [Venkatesh Sivaraman](mailto:venkatesh.sivaraman.98@gmail.com) with any questions.

To run the R code, please be sure to include the `coxed` submodule when you clone the repository (`git clone --recurse-submodules <URL>`).
