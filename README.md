# Sepsis Survey Study Analysis Code

This repository provides the analysis for the paper ``How AI Information Influences Treatment Decisions in Complex Sepsis Cases: A Randomized Experiment''.

The repo includes aggregated outputs and information about the AI predictions; full survey response data is available on request. Please contact [Venkatesh Sivaraman](mailto:venkatesh.sivaraman.98@gmail.com) with your name, affiliation, and reason for requesting the data.

To run the R code, please be sure to include the `coxed` submodule when you clone the repository (`git clone --recurse-submodules <URL>`).
